Task निर्देश

Task पूरा करने के लिए checkbox दबाओ। तारीख या समय बदलने के लिए task के controls इस्तेमाल करो। पुराने अधूरे tasks को एक क्लिक से अगले दिन भेज सकते हो।

Task सूची

Backup Export

अपना profile, subjects, syllabus topics, timetable और tasks JSON फ़ाइल में डाउनलोड करो। फ़ाइल को सुरक्षित जगह रखो।

Backup Import / Restore

पहले export की गई JSON फ़ाइल चुनो। Import करने पर मौजूदा डेटा बदल जाएगा; पहले backup बना लेना बेहतर है।

डेटा और सुरक्षा

  • यह demo browser के localStorage में data रखता है—यह encrypted account या cloud backup नहीं है।
  • Export की गई JSON फ़ाइल में तुम्हारे study details हो सकते हैं; उसे सार्वजनिक जगह पर share न करो।
  • Cloud sync और सुरक्षित login अगले technical चरण में backend/database के साथ बनेंगे।
